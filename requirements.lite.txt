# Alert Dashboard V2 - LITE dependencies (no NEXRAD / radar processing)
#
# Use for the always-on Raspberry Pi build. Excludes the heavy radar stack
# (arm-pyart, scipy, boto3, matplotlib, netCDF4) which is only needed when
# NEXRAD_ENABLED=true. Those run on the main Windows PC, not the Pi.
#
# IMPORTANT: numpy is pinned explicitly. The radar service modules are imported
# at startup by backend/main.py and do `import numpy as np` at module top level
# (nexrad_service, mrms_service, storm_tracking_service). Without numpy the app
# crashes on boot even with radar disabled. Everything heavier than numpy is
# lazy-imported and never touched while NEXRAD_ENABLED=false.
